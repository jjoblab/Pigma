# Chantier 46 — les popups au paquet, l'arborescence commencée

## Pourquoi ce chantier

Le prompt fondateur (§3) propose l'arborescence par FONCTIONNALITÉ :
« un package par fonctionnalité, jamais 100 fichiers dans un seul
paquet, tout ce qui n'est pas l'API publique vit dans internal » —
avec pour `:editor` l'arbre cible `render/ input/ selection/ gutter/
folding/ popups/ accessibility/ internal/`. Le chantier 8 du plan y
vit : « Popups et reprise des fonctionnalités validées — popups dans
le sample ». Le dépôt avait les six modules du prompt ; les paquets,
eux, restaient plats.

## Ce qui a changé

- **`jo.pigma.editor.popups/`** : la popup d'info ancrée (`InfoPopup`
  — l'état texte/ancrage, le remplacement tardif du survol
  asynchrone, ses pinceaux, son dessin) et le bandeau de complétion
  (`SuggestionBand` — les candidats, les abscisses gardées pour le
  toucher, ses pinceaux, son dessin) vivent en classes propres ; la
  géométrie leur parvient par `PopupMetrics` (le paquet ne connaît
  la vue que par ces neuf nombres). `EditorView` délègue : son API
  publique ne bouge PAS (showInfoPopup/replaceInfoPopup/suggestions
  — le harnais le prouve, 27/27 sans retouche des scénarios).
- **`jo.pigma.editor.render/`** : `RenderCache` y déménage (premier
  citoyen du dessin) — `git mv`, le paquet et les imports suivis.
- `EditorView` : 2993 → 2918 lignes ; les cinq peintures de popup et
  les six champs d'état partis avec leurs classes.

## La suite de l'arborescence (le commencement, pas la fin)

Le prompt liste huit paquets : deux vivent (`popups/`, `render/`) ;
les suivants par la même voie — `input/` (EditorInputConnection, les
gestes), `selection/`, `gutter/`, `folding/` — chaque extraction
suivie du harnais complet (le filet qui a tenu ici sans un Scenario
touché).

## Ce qu'on voit (comment rejouer)

    bash scripts/open-harness/run.sh   # 27/27 scénarios verts

Sur l'appareil : rien ne change à l'œil (l'API est la même) — la
popup d'info, le bandeau et la recherche dessinent comme avant, de
leurs classes propres.
