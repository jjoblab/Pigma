# Démonstration du chantier 12 — les guides d'indentation de L2

## Pourquoi ce chantier

Le deuxième consommateur de la structure : **les guides
d'indentation** — les traits verticaux qui matérialisent les niveaux
d'imbrication dans la marge de chaque ligne. Là où les éditeurs
classiques les dérivent des espaces de tête de ligne, Pigma les
dérive de **la chaîne d'appariement de L2** : le guide dit « tu es
dans N blocs ouverts », pas « la ligne commence par N tabulations ».
La structure devient visible en continu, pas seulement auprès du
curseur.

## Ce qui a été construit

- **Le dessin** (`EditorView.drawStructure`) : pour chaque ligne
  visible de profondeur d'entrée `d`, un trait vertical par niveau
  1..`d`, centré sur la bande de 4 colonnes du niveau (le pas
  d'indentation du corpus de démonstration) — un guide de niveau k
  vit à la colonne 4k−2.
- **La profondeur vient du préfixe analysé** :
  `structure.structureOf(ligne − 1).depthOut()` — la lecture suit la
  fenêtre visible, la paresse du préfixe L2 tient (le harnais le
  montre : 33/1 780 lignes analysées après le parcours complet).
- Les guides se dessinent PAR-DESSUS les plans de rendu (les plans
  portent leur fond) en gris translucide — lisibles sur les deux
  thèmes, sans recuisson : le coût par trame est une trentaine de
  `drawLine` (le relevé 5 place le régime établi à 3,46 ms, moteur
  0,06 — les guides s'y fondent).

## Ce qu'on voit (comment rejouer)

    ./gradlew check
    adb install sample/build/outputs/apk/debug/sample-debug.apk

Sur l'appareil : ouvrir la démo Java ou le gros fichier — les rails
verticaux suivent les niveaux ; descendre dans une méthode les
densifie, en remonter les allège. Taper un `}` en trop : la
profondeur ne descend pas sous zéro (la tolérance de L2), les rails
ne disparaissent pas pour autant.

## Limites assumées (et suite)

- **Les guides suivent la structure, pas les espaces** : un code mal
  indenté les verra décalés par rapport au texte — assumé et
  documenté (c'est le choix sémantique : le guide décrit les blocs
  ouverts, la surface n'est pas la profondeur).
- Le pas de 4 colonnes est le pas de la démonstration ; un futur
  réglage le lira de la ligne elle-même si la demande vient.
