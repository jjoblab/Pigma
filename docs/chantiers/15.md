# Démonstration du chantier 15 — les régions pliables

## Pourquoi ce chantier

Le dernier consommateur d'éditeur de L2 : **plier les blocs**. Le
gros fichier (1 780 lignes, 111 classes) s'ouvre d'un geste : la
gouttière porte un marqueur par en-tête de bloc, le toucher le
retourne, les lignes du bloc disparaissent du calcul de hauteur — le
mapping ligne↔pixel devient fonction de l'état des plis.

## Ce qui a été construit

- **L'API L2** : `foldStartsAt(line)` (la profondeur de sortie dépasse
  celle d'entrée — la règle nette : une paire ouverte ET refermée sur
  sa propre ligne ne plie pas) et `foldEndLine(line)` (la première
  ligne qui retombe au niveau d'entrée ; un bloc jamais refermé va
  jusqu'à la dernière ligne).
- **L'état de plis de la vue** : un ensemble d'en-têtes repliés, un
  tableau de lignes cachées et un tableau « lignes visibles avant
  chaque ligne », reconstruits aux changements de plis et aux
  éditions (une passe en O(lignes), jamais par trame). Tout le
  mapping y passe : la ligne de base au dessin, première/dernière
  ligne visible (recherche binaire sur le tableau), le toucher vers
  ligne, la borne de défilement, le curseur.
- **La gouttière tactile** : un toucher dans la marge gauche
  retourne le pli de la ligne touchée (le marqueur : un cadre et son
  signe — moins ouvert, plus replié). Le clavier ne s'y ouvre pas.
- **La vie avec les plis** : le curseur ne vit jamais dans une ligne
  cachée — plier une région qui le porte le ramène à la fin de
  l'en-tête (juste après l'ouvrant, la paire s'y encadre) ; y entrer
  (frappe, placement programmatique) révèle le pli le plus interne.
  Les éditions décalent les en-têtes ; un pli dont l'en-tête n'ouvre
  plus rien se dissout à la reconstruction.
- **Le panneau** : « replié : N pli(s), M ligne(s) cachée(s) ».

## Les deux plantages épinglés par le harnais (et fermés)

1. **L'annotateur lu pendant le remplacement** : le changement de
   langage déclenche l'écouteur du panneau PENDANT la transaction —
   l'ancien annotateur découpait ses anciens jetons dans le nouveau
   texte : bornes hors limites. L'annotateur s'éteint maintenant
   avant le remplacement.
2. **La reconstruction peut annuler le tableau** : révéler le
   curseur ouvrait le dernier pli, la reconstruction annulait le
   tableau des cachées, la boucle de révélation relisait un tableau
   nul. La garde se relit à chaque tour.

## Ce qu'on voit (comment rejouer)

    ./gradlew check
    adb install sample/build/outputs/apk/debug/sample-debug.apk

Sur l'appareil : toucher la marge gauche d'une ligne de signature —
le corps disparaît, le marqueur passe à plus, la hauteur se compacte
(le défilement suit) ; re-toucher — le bloc revient. Taper alors que
le curseur serait caché : le pli s'ouvre pour lui.

## Limites assumées (et suite)

- La règle nette : une paire refermée sur sa propre ligne ne plie
  pas ; `} else {` (sortie égale à l'entrée) ne plie pas non plus —
  les plis exacts par paire suivront si la demande vient.
- Le pli se mémorise par numéro de ligne : une édition qui détruit
  l'ouvrant dissout le pli (à la reconstruction), pas de ré-anage
  syntaxique de l'en-tête.
- Suite : L3, l'annotateur sémantique (chantier 16).
