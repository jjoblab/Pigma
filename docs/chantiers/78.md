# Chantier 78 — l'historique local en versions, l'usage qui montre son code (B7)

## La consigne

Le défaut B7 du rapport, côté historique : une trace PAR CARACTÈRE
(64 traces = quelques secondes de frappe), pas d'état d'avant (ni
diff, ni plage), une restauration dangereuse (numéro de ligne non
suivi → écrasement d'une autre ligne ; texte tronqué à 400
caractères → perte de fin de ligne).

## L'historique, repensé en versions

`LocalHistory` réécrit :

- **la version par geste** : la plage remplacée et son texte
  AVANT, l'étiquette, le moment. La FRAPPE se regroupe : une
  écriture qui suit la précédente de moins de 2 secondes, de
  frappe des deux côtés, sur des plages qui se touchent, ÉTEND la
  version ouverte (la réunion des plages, le texte d'avant fusionné)
  — une phrase tapée tient UNE version, un collage ou une
  complétion vit sa version étiquetée à soi ;
- **le budget en caractères archivés** (32 768) remplace le plafond
  de 64 traces : les versions anciennes s'évincent quand l'espace
  se dépasse, une grosse version vaut ce qu'elle pèse ;
- **la restauration remet la plage exacte** : la version porte la
  région OCCUPÉE après le geste (le texte posé y vit) — la
  restauration remplace cette région par le texte d'avant. Une
  insertion s'y retire entière ; plus d'écrasement d'une ligne
  décalée (la plage vit en décalages du document, bornée au
  présent), plus de troncature (le texte d'avant est entier ou il
  ne l'était pas déjà).

Côté vue : `applyEdit` capture le texte d'avant la plage et
l'enregistre après l'écriture (`recordLocalTrace` par caractère
disparaît — la notification n'a plus à deviner). La carte
`HistoryCard` lit les versions (l'extrait d'avant s'y déplie, la
pastille restaure).

## Les usages montrent leur code

`UsageCard.Usage` gagne l'**extrait de la ligne** (coupé à 80
caractères à la collecte, 60 à l'affichage) : la rangée porte le
symbole et sa localisation en tête, le code de la ligne au
dessous — le rapport demandait l'extrait avec le mot en contexte.

## La preuve

- `LocalHistoryTest` (4 tests) : le regroupement par pause (trois
  touches = une version, la pause en ouvre une autre, le geste
  étiqueté ne se groupe pas), la réunion des plages, l'éviction par
  budget, la lecture du dernier au premier ;
- le scénario du vieux harnais s'adapte : la version se déplie et
  restaure la plage du passé (la double annulation rend l'original)
  — 49/49 ;
- `./gradlew check` complet vert.
