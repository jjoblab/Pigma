# Démonstration du chantier 14 — le surlignage de portée et la règle du guide

## Pourquoi ce chantier

Deux demandes : le guide d'indentation devait **s'arrêter une ligne
avant le fermant** (le fil vertical se termine au-dessus du `}`,
comme le croquis reçu :

    public méthode/classe {
     |
    }

), et la portée du curseur devait se voir — le bloc englobant se
teinte en fond, le dernier consommateur « lecture » de L2.

## Ce qui a été construit

- **`StructureDocument.scopeAt(offset)`** : la plage du bloc le plus
  interne qui englobe le curseur. La profondeur se lit à la position
  exacte du curseur (sur la ligne de l'ouvrant, APRÈS l'accolade,
  c'est le bloc nouveau ; AVANT, le parent) — puis les bornes se
  cherchent par la chaîne de profondeur : l'ouvrant vit après la
  dernière ligne d'avant qui referme sous ce niveau, le fermant à la
  première ligne qui y retombe. Un bloc jamais refermé va jusqu'à la
  dernière ligne ; au niveau racine, pas de portée (`null`).
- **La bande de fond** dans la vue : un rect translucide sur les
  lignes de la portée, borné à la fenêtre visible, peint AVANT le
  texte (le texte se dessine dessus). Le calcul partage le cache de
  la paire d'appariement : un déplacement de curseur ne paie les
  marches qu'une fois.
- **La règle du guide corrigée** : le guide d'un niveau ne se dessine
  que si le niveau couvre TOUTE la ligne —
  `min(profondeur d'entrée, profondeur de sortie)`. Un niveau qui
  s'ouvre en fin de ligne ne guide pas cette ligne, un niveau qui se
  ferme en cours de ligne ne la guide pas non plus : le fil commence
  APRÈS la ligne de l'ouvrant et s'arrête UNE LIGNE AVANT le
  fermant — exactement le croquis.

## Ce qu'on voit (comment rejouer)

    ./gradlew check
    adb install sample/build/outputs/apk/debug/sample-debug.apk

Sur l'appareil : toucher dans un corps de méthode — la bande se teinte
sur les lignes du bloc englobant ; remonter le curseur vers la classe
— la bande s'élargit à la classe ; le toucher au-dessus de la
première accolade — plus de bande (racine). Et les guides : les fils
verticaux s'arrêtent maintenant une ligne au-dessus de chaque `}`.

## Limites assumées (et suite)

- Les bornes de portée se cherchent par la chaîne de profondeur — la
  plage est exacte aux lignes près ; le fermant d'un bloc refermé au
  milieu d'une ligne portée par la ligne suivante... non : la borne
  est la LIGNE qui retombe au niveau, la plage en lignes suffit au
  surlignage (une plage en colonnes suivra si un consommateur l'exige).
- Suite : les régions pliables (chantier 15) et l'annotateur
  sémantique (chantier 16) — la fin de L2 et L3.
