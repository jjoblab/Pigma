# Démonstration du chantier 0 — squelette du dépôt

## Ce qui a été construit

- Dépôt `jjoblab/Pigma`, branche `main`, historique Git propre (un commit
  par changement logique).
- Build Gradle **sans `build-logic`, sans `buildSrc`, sans `includeBuild`** :
  les conventions communes (Checkstyle, politique, raccourcis `check` et
  `test`) vivent dans le `build.gradle.kts` racine, dans un bloc
  `subprojects { }` court.
- Catalogue de versions unique `gradle/libs.versions.toml` (AGP 8.7.3,
  Checkstyle 10.18.2, JUnit 4.13.2, SDK 35/26/35) : aucune version
  ailleurs.
- Wrapper Gradle 8.10.2 **épinglé par somme de contrôle SHA-256**
  (`distributionSha256Sum` dans `gradle/wrapper/gradle-wrapper.properties`).
- Garde-fous automatiques :
  - `scripts/check-code-policy` : identifiants ASCII, motifs interdits
    dans les commentaires, mots français dans les identifiants
    (`scripts/french-words.txt`), Javadoc des types publics ; mode
    `--selftest` sur `scripts/policy-fixtures/Violations.java` ;
  - `scripts/check-forbidden-refs` : références interdites dans les
    fichiers versionnés, motifs fournis par l'environnement
    (`PIGMA_FORBIDDEN_REFS` ou `config/forbidden-refs.local`, jamais
    commités) ;
  - crochet pre-commit (`scripts/hooks/pre-commit`) qui exécute les deux.
- Module `:sample` : application vide sans AndroidX (Activity du cadre de
  travail, thème Material du système), un test unitaire JVM.
- Documentation de départ : `README.md`, `docs/ARCHITECTURE.md`,
  `docs/PORTAGE.md`, trois décisions dans `docs/decisions/`, étude de
  conception recopiée dans `docs/etude-codeassist.md` (deux mentions
  neutralisées conformément à la règle des références interdites — voir
  la note de recopie en tête du document).

## Ce qu'on voit dans le sample

L'application s'ouvre sur un écran unique affichant « Pigma » et la
mention « Application de démonstration ». Rien d'autre : ce chantier
prouve uniquement que la chaîne de build produit un APK installable et
que l'application démarre. La saisie de texte, l'annulation et la
coloration arriveront avec les chantiers suivants (`:core` puis
`:syntax`).

## Comment vérifier à la main

1. Compiler : `./gradlew :sample:assembleDebug` (prérequis : JDK 17,
   SDK Android via `local.properties` ou `ANDROID_HOME`, Python 3).
2. L'APK est dans `sample/build/outputs/apk/debug/sample-debug.apk`
   (environ 7 Ko).
3. Installer sur un appareil ou un émulateur :
   `adb install sample/build/outputs/apk/debug/sample-debug.apk`.
4. Ouvrir l'application « Pigma » : l'écran d'accueil s'affiche.

## Décisions à signaler au propriétaire

- **Visibilité du dépôt GitHub** : créé **privé** par prudence ; à rendre
  public le jour voulu (aucune incidence sur le code).
- **Collision connue de la politique** : « session » et « étape » sont
  interdits dans les commentaires mais sont aussi des mots du domaine
  d'un éditeur (session LSP, étape de lexage) — décision à prendre le
  jour où elle se présente (consignée dans
  `docs/decisions/002-controles-de-politique.md`).
- **Le contenu de `check`** inclut aujourd'hui le lint AGP (léger sur un
  module minimal) ; si sa durée devient un problème sur téléphone, le
  restreindre relève d'une décision explicite.
- **Pas de fichier `LICENSE`** pour l'instant : la licence de la
  bibliothèque est un choix du propriétaire, à consigner dans
  `docs/decisions/` et dans le `NOTICE` au moment de la publication.
