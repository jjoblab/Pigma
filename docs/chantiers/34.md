# Démonstration du chantier 34 — le traîné-déposé de texte

## Pourquoi ce chantier

La suite « à décider » le nommait : déplacer du texte en le
traînant — le geste que tout éditeur tactile se doit d'avoir, et
que la mission n'avait pas. La sélection se déplaçait par
couper-coller seulement.

## Ce qui a changé

- **Le geste** : un appui dans le TEXTE d'une sélection vivante
  (pas sur ses poignées) arme le traîné-déposé ; le glissé qui
  suit, avant le seuil de l'appui long, l'engage ; le curseur de
  dépôt suit le doigt (le caractère le plus proche — il se dessine
  à la place du curseur le temps du geste, la sélection reste
  teintée : le doigt voit où le texte se posera).
- **Le dépôt** : le texte sélectionné se déplace en UNE SEULE unité
  à défaire (la suppression et l'insertion dans une transaction) ;
  un dépôt après la sélection décale la cible de la longueur
  déplacée ; le curseur se pose après le texte déposé.
- **Un dépôt dans la sélection (ou sur elle) ne déplace rien** :
  aucune unité ne naît — le texte reste où il est.
- **Les voix voisines restent** : les poignées se saisissent
  toujours d'abord (un mot court — trois colonnes — se saisit par
  elles avant son milieu) ; l'appui long qui glit étend toujours la
  sélection ; un simple tap dans la sélection pose toujours le
  curseur.

## Ce qu'on voit (comment rejouer)

    ./gradlew check
    bash scripts/open-harness/run.sh

Sur l'appareil : double-tap sur un mot, puis saisir le mot AU
MILIEU et le traîner — le curseur suit le doigt, le mot se pose au
lâcher, « Annuler » le rend. Traîner sur une autre ligne : le texte
traverse les lignes.

## Résultats constatés

| Mesure | Valeur |
| --- | --- |
| Tests au dépôt | 120 méthodes de test vertes (128 exécutions) |
| Harnais JVM | **23 scénarios verts** — le traîné-déposé : le dépôt avant la sélection (texte exact au point de dépôt, curseur après le texte, une unité à défaire), la sélection longue semée par l'appui long qui glit, le dépôt sur la ligne au-dessus (le texte traverse les lignes), l'annulation rend le texte à chaque fois |
| Coût du geste | le curseur de dépôt se pose à O(1) par déplacement (le caractère le plus proche), le dépôt est une transaction ordinaire (la frappe y paie le même chemin) |

## Limites assumées (et suite)

- Le traîné ne défile pas : le point de dépôt se lit dans la
  fenêtre visible (un dépôt hors fenêtre demande de défiler puis de
  re-traîner) — le défilement automatique au bord suivra si la
  mesure le demande.
- Le traîné n'ouvre pas la loupe : le curseur de dépôt est au
  caractère près, la loupe de précision vit dans le traînement des
  poignées — l'unir au traîné suivra le même besoin.
- Le texte traîné ne « flotte » pas au doigt (pas d'aperçu flottant
  du texte en cours de geste) : la sélection teintée et le curseur
  de dépôt portent le geste — l'aperçu flottant est une décision de
  dessin à prendre si le terrain le demande.
