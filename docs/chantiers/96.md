# Chantier 96 — la paperasse rattrape le code (D16, D19/D20)

« Va pour D16, D19/D20 » — les deux défauts d'écriture que la feuille
portait « à reprendre au fil des chantiers touchés », plus la demande
du terrain : « les READMEs doivent refléter réellement le code dans
chaque module, le mode d'utilisation md aussi » (le chantier 95 a
changé le code — la paperasse le rattrape).

## D16 — `ARCHITECTURE.md` décrivait toujours `accessibility/` « à créer »

Le défaut : le plan du package `:editor` décrivait une structure
d'intention (`Editor.java` « façade hôte » qui n'existe pas, un
`render/` ailleurs, `accessibility/` nu — le package vit depuis le
chantier 77). Le correctif : l'arbre du module porte les fichiers et
packages RÉELS — `EditorView`, `EditorThemes`, `render/`
(`Painter`, `SeverityIcon`), `input/`, `selection/`, `gutter/`
(la minimap et sa barre), `folding/`, `popups/` (les vingt-neuf
cartes, `PopupHost`, `CardBase`/`ListCard`), `accessibility/`
(`EditorAccessibility`, `PopupAccessibility` — le nœud éditable, les
rangées virtuelles), `lsp/` (la façade `LspEditor`), `internal/`
(layout, render, scroll, search, touch — la géométrie extraite).

## D19/D20 — la coquille `MEMORRY_ANCHOR_INTERVAL` et l'historique mort

La coquille vivait à `EditorView` (onDraw — la relecture de l'ancre
de mémoire) : « MEMORRY_ANCHOR_INTERVAL » devient « l'intervalle
MEMORY_ANCHOR_INTERVAL » — la constante, elle, avait toujours été
correcte. L'historique mort dans les commentaires : le chantier 95 a
retiré le sien en passant (`hostAppliesLanguage` et le bloc EmmyLua
de l'écran — le code parti n'a plus de commentaire qui le raconte) ;
les commentaires d'historique restants se relisent au fil des
chantiers touchés, la règle de conduite demeure.

## Les README reflètent le code

- **`editor/README.md`** — la rangée `popups/` portait NEUF cartes
  (l'avant-chantier 88) : elle porte les VINGT-NEUF cartes réelles
  (recherche/remplacement, aller-à ligne/symbole/fichier, complétion
  entière au panneau de documentation, signature aux surcharges,
  survol Markdown défilant, sélection, débordement, historique,
  diagnostic aux correctifs, actions rapides, renommage à l'aperçu,
  usages, cibles, problèmes, presse-papiers, structure au filtre,
  import, définition en aperçu, récents, entourer, extraits,
  sélecteur de couleur) et le `PopupHost` (un seul état « popup
  active ») ; l'extrait d'intégration porte `openDocument` d'un
  trait (le chantier 95) ;
- **`INTEGRATION.md`** (le mode d'utilisation) — les deux traits du
  95 : `editor.openDocument(...)` (extraits standard + récents) et
  `lsp.connectEmmyLua(context, texte)` (l'espace de travail, le
  document, le processus, la liaison — d'un seul appel) ;
- **`core/`, `syntax/`, `analysis/`, `bench/`, `lsp/`,
  `sample/`** — relus : leurs descriptions portent le code qu'ils
  décrivent (le sample décrit l'écran de démonstration — l'écran
  a maigri au 95, sa description ne changeait rien de faux ; le
  `:lsp` porte le module de PROTOCOLE, la façade vit au `:editor`).
