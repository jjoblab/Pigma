# Démonstration du chantier 35 — la consolidation : le hors normes aux autres langages

## Pourquoi ce chantier

La suite « à décider » le nommait : la consolidation. Le hors
normes n'existait qu'en Java — la fenêtre, les tranches, le mode
gros fichier et la paresse de ligne ne s'étaient éprouvés à cette
échelle que sur un seul lexeur.

## Ce qui a changé

- **Le générateur par langage** : `DemoTexts.hugeFile(language)` —
  le bloc propre au langage (élément XML, objet JSON, classe
  Kotlin, CREATE/INSERT SQL) répété jusqu'à 52 000 lignes, chacun
  caché au premier appel. Le Java garde son bouton « 50k l. » (la
  continuité du journal).
- **Le bouton « 50k ⨯ »** : chaque clic ouvre le langage suivant du
  cycle (XML, JSON, Kotlin, SQL, Java…) — le texte se génère AU
  CLIC (jamais à l'ouverture de l'application), et l'étiquette du
  scénario porte le langage : la ligne du journal copié lira
  « première coloration - fichier 52 000 lignes (XML) » — le
  relevé saura qui il mesure.

## Ce qu'on voit (comment rejouer)

    ./gradlew check
    bash scripts/open-harness/run.sh

Sur l'appareil : cliquer « 50k ⨯ » — le XML s'ouvre, le panneau
montte 52 000 lignes et le mode gros fichier ; cliquer encore — le
JSON, puis Kotlin, puis SQL, puis Java, et le cycle recommence. Le
journal porte le langage à chaque ouverture.

## Résultats constatés (harnais JVM)

| Langage | Lignes | Jetons | Fond |
| --- | --- | --- | --- |
| XML | 52 005 | 375 573 | 18 ms |
| JSON | 52 003 | 332 802 | 20 ms |
| Kotlin | 52 011 | 563 421 | 33 ms |
| SQL | 52 011 | 42 553 | 11 ms |

**24 scénarios verts** — chaque langage vérifié : 52 000 lignes et
plus, le mode gros fichier actif, le texte du bon langage, le
remplissement complet ; la frappe au milieu du hors normes SQL
relit UNE ligne (la paresse tient sur chaque lexeur). Tests au
dépôt : 120 méthodes de test vertes.

## Limites assumées (et suite)

- Le JSON de démonstration porte une virgule traînante (structure
  d'exercice du lexeur, non d'analyseur strict) — le lexeur s'en
  moque, l'analyseur n'est pas branché dessus.
- Le cycle ne mesure rien de lui-même : le relevé 17 dira les fonds
  et les premières colorations par langage sur l'appareil — c'est
  la mesure qui manquait à la consolidation.
- Le XML et le JSON partagent la famille générique : leurs comptes
  de jetons par ligne sont plus pauvres que Java/Kotlin (les
  lexeurs générés) — la fenêtre s'y paie d'autant moins.
